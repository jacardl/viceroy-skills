# 写作风格规范 & 版式参考

## 必须遵守
- **口语对话感**：读起来像作者在跟你喝茶聊天，不是写论文
- **具体 > 模糊**：用真实数字、真实案例、真实对话
- **立场鲜明**：作者有观点，不做理中客
- **用强比喻**：每个抽象概念必须配一个生活化的比喻

## 严禁出现
- ❌ 任何 emoji 或表情符号
- ❌ 任何 bullet point（`· ` 或 `- ` 开头的列表）
- ❌ 企业全名（用"某品牌""某平台"或品类词代替）
- ❌ "本文由 xxx 自动发布"等 branding
- ❌ 超过 3 个分隔符 `· · ·`（每篇 2–3 个最佳）
- ❌ 超过 5 个数据点（每个数据用深用透，不要堆砌）

## 标点与格式
- 中文引号「」代替英文引号
- 数字用阿拉伯数字（"3年"不是"三年"）
- 百分比用 % 符号（"88%"不是"百分之八十八"）
- 英文术语第一次出现附中文翻译（"GEO（生成式引擎优化）"）

## 标题规范
| 位置 | 规则 |
|------|------|
| 主标题 | 16–24 字，含 GEO 或 AI 搜索相关词 |
| 副标题 | 可选，补充角度或悬念 |
| 风格 | 悬念感 > 概括感（「用户不搜了，AI 替你选了」 > 「GEO 与 SEO 的区别」）|

## HTML 模板
```html
<!DOCTYPE html>
<html>
<head>
<meta charset="utf-8">
<title>【标题】</title>
</head>
<body style="background:#f5f4ed; font-family:Georgia,'Noto Serif SC',serif; max-width:680px; margin:0 auto; padding:40px 20px; color:#1a1a1a; line-height:1.8; font-size:17px;">
<p style="font-size:13px; color:#888; margin-bottom:30px;">文 / 刘生</p>

<h1 style="font-size:24px; font-weight:bold; margin-bottom:8px; color:#1a1a1a;">【标题】</h1>

<!-- 开头钩子 -->
<p>事情是这样的。……</p>

<p style="text-align:center; color:#888; margin:30px 0;">· · ·</p>

<!-- 正文展开 -->

<p style="text-align:right; color:#888; font-size:13px; margin-top:40px;"> 题图：AI 生成</p>
</body>
</html>
```
- `background:#f5f4ed` 固定背景色
- 结语段不加任何 CTA 或关注引导

## 文章结构（六模块）
1. 开头钩子（150–300字）：真实故事 / 朋友求助 / 具体痛点
2. 核心数据锚点（200–400字）：可溯源数字 + 一句话解读
3. 逻辑展开（800–2000字）：对比推进（SEO vs GEO / 旧 vs 新）
4. 行动框架（200–500字）：五步法 / 两种状态对比 / 三个误区
5. 行业信号（200–400字）：真实商业事件收尾
6. 结语钩子（80–150字）：回扣开头 + 认知升级 + 金句
