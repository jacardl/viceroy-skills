# H2 标题「不是X是Y」误检陷阱（2026-08-23 实录）

## 问题现象

草稿正文已清零 `不是X是Y`，但 validate 仍报告 1 处命中。

根本原因：`validate_zhili_article.py` 对 HTML 去掉标签后的纯文本做正则检测。H2 标题和紧随其下的正文在 strip 标签后被拼到同一个「段落」里（`</p><h2>` 分隔符被当作段落边界），导致 H2 标题里的「不是」和正文的「是」落入同一个 `para`，触发 `不是[^，。,\n]{1,40}[，,][^是\n]{1,40}是` 正则。

## 实录

标题「五、实战用法：过滤网，不是撒网」：

```
# strip 后 flat text（简化）
五、实战用法：过滤网，不是撒网光有工具不够，关键是改变找工作的思路...

# 正则匹配到：
不是撒网光有工具不够，关键是

# 匹配路径：「不是撒网」（在 H2 里）→ 逗号 → 「是」（在下一段开头）
```

解法：H2 标题里完全避免「不是X是Y」句式，不管 X 和 Y 距离多远。改用其他对仗结构（如「精准过滤，按需投递」）。

## 避坑原则

写 H2 标题时：
- 标题含「不是」或「是」之一可以
- 标题同时含「不是」和「是」会触发误检，无论它们在标题里相隔多远
- 最佳实践：H2 标题避免所有 renwei 禁用句式，不只依赖正文清零

## 验证步骤

写完标题后，额外跑一遍草稿 markdown：

```bash
grep -n "不是.*是" /tmp/draft.md
```

若 H2 标题触发，检查该行上下文确认是否在正文里。如果只在标题里，修改标题即可。
