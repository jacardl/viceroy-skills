# 标题字节预检参考（2026-08-16 实录）

## 背景

微信标题硬限制 ≤60 字节（`sum(3 if ord(c) > 127 else 1 for c in title)`）。
`validate_zhili_article.py` 会检查，但很多 agent 在渲染后才发现，超了就得改完标题再重渲染、重新验证——多走一轮。

## 正确做法：草稿阶段先预检

写完标题后立即运行，不等 validate：

```python
title = "你的标题"
bc = sum(3 if ord(c) > 127 else 1 for c in title)
print(f"{bc} bytes {'✅' if bc <= 60 else '❌ 超限'}")
```

超了就先改标题，再写正文，再渲染。

## 本次实录

| 标题 | 字节数 | 结果 |
|------|--------|------|
| 查邮箱是否注册过主流网站？这个开源工具一查便知 | 69 | ❌ |
| 查邮箱是否已注册？这个开源工具全搞定 | 54 | ✅ |

## 常见超标模式

- 带"主流网站"的标题：每个汉字增 1 byte，"主流"+"网站"合计 6 bytes
- 完整标题尽量控制在 20 字以内
- "全搞定"比"一查便知"省 6 bytes（"搞定"2字 vs "一查便知"4字）
