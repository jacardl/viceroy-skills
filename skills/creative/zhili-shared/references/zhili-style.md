## 1. 样式A CSS（羊皮纸 · 标准模板 · 2026-05-30 固化）

### 样式A 核心参数

| 属性 | 值 |
|------|-----|
| 背景色 | `#f5f4ed`（暖羊皮纸） |
| 正文字体 | `'Noto Serif SC', Georgia, serif`（逗号后有空格，Noto 在前） |
| H2 标题 | `font-weight:700;font-size:20px;color:#1B365D;border-left:4px solid #00d4aa;padding-left:12px;margin:0 0 16px 0` |
| 强调色（数据/核心） | `#c9553d`（砖红） |
| 强调色（关键词/重点） | `#1B365D`（墨蓝） |
| 警示/核心洞察背景 | `#fff3b0`（淡黄底） |
| 引言/摘要样式 | 左边框 `#1B365D` + `background:#f0efe8` + 斜体 |
| 分隔线 | `· · ·` 居中，`color:#c9553d` |
| 代码块 | `background:#1e1e1e`，白色文字 `#e8e8e8` |
| 正文段落 | `font-size:16px;line-height:1.85;color:#2c2c2c;margin:0 0 28px 0` |

### preflight CSS 精确匹配规则

> ⚠️ preflight.py 用**子串精确匹配**检查 CSS，以下值必须完全一致：

| 元素 | 精确 style 字符串 | 易错点 |
|------|-------------------|--------|
| H2 | `font-weight:700;font-size:20px;color:#1B365D;border-left:4px solid #00d4aa;padding-left:12px;margin:0 0 16px 0` | `font-size` 和 `color` 必须相邻；`font-weight:700` 必须在最前 |
| body/div | `background:#f5f4ed` | 不是 `background-color:` |
| P | `font-size:16px;line-height:1.85;color:#2c2c2c;margin:0 0 28px 0` | 段距是 `28px` 不是 `14px` |
| 作者行 | `font-size:13px;color:#7c6f64` | 颜色是 `#7c6f64` 不是 `#6b665b` |
| 来源行 | `font-family:monospace` | |

**⚠️ H2 font-size 和 color 必须相邻**：`font-size:20px;color:#1B365D`（中间无其他属性）。

### ❌ 禁止事项

- 禁止 `#ffffff` 纯白背景（破坏羊皮纸一致性）
- 禁止 `#00d4aa` 用于主色调或文字色（**只允许 H2 左边框**）
- 禁止删除 `font-family` 中的 `Georgia`
- 禁止 `background-color:`，一律用 `background:`
- 禁止 `margin-top`/`padding-top`，只用 `margin-bottom`/`padding-bottom`

## 2. stop-slop 文风检查（AI 味去除术）

> 核心思路：AI 写东西有套路，套路让人读起来像机器。这套检查表专门治这个。
> **中文适配**：英文 stop-slop 的"No em-dashes"对中文不适用（中文破折号用法不同）。

### 废话填充词（出现 ≥3 个 = AI 味）

| # | 中文废话 | 替换建议 |
|---|---------|---------|
| 1 | 值得注意的是 | 直接删 |
| 2 | 实际上、其实 | 直接删 |
| 3 | 那么、那么就 | 很多是噪音，可删 |
| 4 | 大家/我们都知道 | 谁？直接说 |
| 5 | 从某种意义上来说 | 要说就说清楚 |
| 6 | 归根结底 | 直接说结论 |
| 7 | 不得不承认 | 直接删 |
| 8 | 想必、应该（猜测语气） | 不确定就别用 |
| 9 | 毫无疑问 | 直接删 |
| 10 | 必须承认 | 直接删 |
| 11 | 我想说的是 | 删，直接开口就说 |
| 12 | 相信大家都知道 | 谁？不点名就说 |

### 句式结构（5 条）

- [ ] 没有「首先、其次、最后、总之」套路（三板斧）
- [ ] 没有「一方面、另一方面」平衡结构（假辩证）
- [ ] 没有「随着…的发展」宏大叙事开头
- [ ] 没有无主语句（「已被广泛认可」）
- [ ] 没有因果废话（「因为 X，所以 X，这说明」）

### 中文 AI 黑话池（用一次扣一分）

```
突破瓶颈 → 解决
赋能 → 帮助
持续迭代 → 更新
深度赋能 → 提高
构建生态 → 攒人
引领变革 → 搅局

解决方案 → 方法
颠覆性创新 → 新的做法
落地 → 实施
```

## 3. renwei 人味儿写作（位置 + 代价 + 手迹）

> 🎯 目的：把「AI 写得整齐」升级为「有手迹感」。写作时脑子里装三件事：
> 1. **位置**：作者站在哪里说话？（不是百科词条位）
> 2. **代价**：每段有没有具体数字/具体场景/身体感觉？（不是"非常强大"）
> 3. **手迹**：句尾"呢""吧""了"、口语词有没有被删？（删了人没了）

### 三原则

**位置**：AI 写的"CodeGraph 是一个 AI 驱动的代码图谱工具"——谁都能说，没位置。
→ 改成"上周给我弟讲他大学 C++ 作业的指针绕晕，我就想起 CodeGraph——它干的事就是把代码变成你能看懂的图"

**代价**：
- 数字细节：43 块肌肉 / 3.2k stars / 11 个文件
- 场景细节：饭局、面试官压力测试、打太平天国
- 身体感觉：绕晕、卡住、一晚上没睡

**手迹**：
- 句尾"呢""吧""了"——别删
- "其实""说白了""你想想"——别换成"客观而言"
- 忽长忽短的呼吸——别为工整而强行对齐

### renwei 套话清单（11 项，任意命中 ≥3 → 打回重写）

| # | 检查项 | 合格标准 |
|---|--------|----------|
| 1 | 「不是 X 而是 Y」句式 | 0 处 |
| 2 | 排比三连 | 0 处 |
| 3 | `——` 破折号 | 0 处 |
| 4 | 段落级加粗（形容词/副词/修饰性） | ≤1 处/节 |
| 5 | AI 套话（"非常""极其""令人""值得"） | 0 处 |
| 6 | 意义拔高（"这不仅是 X，更是 Y"） | 0 处 |
| 7 | 万能展望结尾（"未来属于..."） | 0 处 |
| 8 | 谄媚语气 | 0 处 |
| 9 | emoji 装饰 | 0 处 |
| 10 | 填充对冲（"当然也不排除"） | 0 处 |
| 11 | AI 赞美形容词（强大、优雅、惊艳、出色） | 0 处——用具体场景代替 |

### 「不是 X 是 Y」安全改法

> ⚠️ 检测宽度最大 40 字符，即使改成「没有 X 有 Y」，中间出现独立「是」字仍被捕获。

- ❌「它不是银弹」→ ✅「它并非银弹」
- ❌「问题不是 A，而是 B」→ ✅「问题不在于 A，而在于 B」
- ❌「好代码不是因为写得多而值钱」→ ✅「好代码写得多不值钱，写在该写的地方才值钱」

### 破折号替换原则

- 「A——B」（解释说明）→ 「A，B」
- 「A——B」（转折）→ 「A。B」

## 5. HTML 拼接技术规范

**问题根因**：字符串列表 + `'\n\n'.join()` 会在 block 之间插入换行符，导致 JSON payload 含 `\n`，微信渲染出多余空白段落。

**正确做法**：
```python
# ✅ 每个块写成一行，块间零分隔符
blocks = [
    '<p style="margin:0 0 28px 0;font-size:16px;line-height:1.85;color:#2c2c2c;">第一段</p>',
    '<p style="margin:0 0 28px 0;font-size:16px;line-height:1.85;color:#2c2c2c;">第二段</p>',
]
html_content = ''.join(blocks)  # 零分隔符

# ❌ 错误：'\n\n'.join() 会导致 JSON payload 含 \n
# ❌ 错误：代码块中有真实换行符，应用 <br>
```

**验证**：
```bash
grep -n '^$' /tmp/article.html   # 应为 0（无纯空行）
grep -n '\*\*' /tmp/article.html  # 应为空（无 Markdown 残留）
```

### 代码块规则

- `<code>` 必须设 `color:#e8e8e8`（浅灰白）+ 等宽字体 `font-family:'Consolas','Monaco',monospace`
- 禁止裸 `<code>` 没有外层 `<pre>` 包裹
- 多行命令用 `<br>` 换行，不用真实换行符

## 6. WeChat API 关键教训

### JSON 编码（2026-05-30 三阶段排查确认）

- ✅ 正确：`json.dumps(payload, ensure_ascii=False).encode("utf-8")`，`Content-Type: application/json`（绝对不能带 `charset=utf-8`）
- ❌ `ensure_ascii=True`（默认）→ 中文变 `\uXXXX` 字面量
- ❌ `ensure_ascii=False` + `charset=utf-8` → WeChat JSON 管线无法解码

### 封面图上传

⚠️ `thumb_media_id` 必须来自 `material/add_material?type=image`，不能用 `media/upload?type=thumb`（返回临时素材 ID，报 40007）。

### 草稿图片显示 400

HTML 里的 img src URL 被截断（缺少 `?from=appmsg` 后缀）。用完整 mmbiz URL（157-163字符）注入。

### execute_code sandbox 破坏含中文/特殊字符的字符串

HTML 文件读写 → 用 **terminal Python**（`python3 << 'EOF'` 或 `python3 script.py`），不要用 `execute_code`。
