# zhilicomments 结构要求速查（2026-07-16 实战补录）

## P 段落数要求：≥ 20

preflight.py 第5步检查 `P ≥ 20（短评 ≥20 段）`。这个数字很容易被忽略——内容通过、格式通过、但 P 数量不够导致 44/44 失败。

**典型错误**：写完发现正文只有 12 段，需要扩充到 20 段。

**快速诊断**：
```python
import re
html = open('/tmp/article.html').read()
paras = re.findall(r'<p style[^>]*>([^<]+)</p>', html)
print(f"P 段落数: {len(paras)}")
```

**补救方法**：找最短的段落（20-40字的段落），每个扩充 30-40 字，而不是增加新段落。

## H2 数量要求：≥ 3（建议 4）

zhilicomments 短评的结构不是六段式，不需要那么多 H2，但 preflight 仍然检查 H2 ≥ 3。建议 4 个 H2 覆盖：项目背景、核心观点、深度分析、收尾金句。

## 中文冒号和破折号：写的时候就不许用

preflight 扫描整个 HTML 文本（含 title 标签、来源行），自然书写就会触发。

常见踩坑：
- `有意思的是：` → 改为 `有意思的是，` 或 `有意思的是——`（不能用中文冒号，破折号也禁用）
- `这意味着——` → 改为 `这意味着，` 或 `意思是`
- `来源：纽约时报` → 改为 `来源 - 纽约时报`

**铁律**：写的时候就不许用，不要写完再全局替换。
