# 0. 本清单范围

本清单分为八类：

1. **符合性评审材料 / 条件**：不计分，但不满足可能被否决；
2. **经济标材料**：用于报价评分和报价合规；
3. **商务标评分材料**：评分表明确要求、可计分或缺失会扣分的材料；
4. **技术标评分材料**：评分表明确要求的方案、视频、案例、证明、截图、报告等；
5. **技术评分视频 / 附件命名建议**：按评分项逐条绑定；
6. **技术规格强制响应材料**：评分表之外的星号条款、承诺书、强制技术要求；
7. **不纳入本清单的材料**：内部辅助或方案论证材料；
8. **执行优先级**：P0-P4。

以下材料不纳入“必备应标材料”，除非招标文件明确要求：讲标稿、答辩 PPT、行业研究报告、产品白皮书、客户推荐信、内部报价测算表等。

# 8. 执行优先级

## 8.1 P0：否决风险，必须先完成

1. 投标保证金；
2. 法定代表人证明书 / 授权委托书；
3. 投标有效期承诺；
4. 营业执照 / 法人资格；
5. 信用中国查询；
6. 中国裁判文书网查询；
7. 非联合体、不转包、不分包承诺；
8. 报价不超限价核验；
9. 报价修正风险复核；
10. 全文实质性响应检查。

## 8.2 P1：直接计分材料

- 商务标评分材料；
- 技术标评分材料；
- 评分表明确要求的视频 / 方案 / 证明 / 案例 / 第三方报告。

## 8.3 P2：强支撑材料

- 每个视频对应截图包；
- 评分项—视频文件—投标文件页码索引表；
- 原厂授权证明；
- 案例证明补充材料；
- 产品能力截图 / 仓库链接 / 白皮书节选。

## 8.4 P3：技术规格强制响应材料

- 星号条款响应；
- 承诺书；
- 技术规格要求的部署、接口、培训、售后、文档说明。

## 8.5 P4：增强材料 / 内部辅助材料

- 讲标稿；
- 答辩 PPT；
- 评委追问清单；
- 行业案例；
- 内部报价测算表。
