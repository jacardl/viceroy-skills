## 1. 项目本质判断

东航 APP 超级智能体建设项目被拆解为：

> 以旅客全旅程为核心的 **AI Agent 平台建设项目**，目标是将 APP 从功能型工具升级为智能服务入口和交易闭环中枢。

核心需求结构：

1. **AI 能力层**：多智能体调度、意图识别、小模型微调、长短期记忆、用户画像、云资源；
2. **用户理解层**：从被动客服到主动理解用户行为与意图，形成实时决策中枢；
3. **业务场景层**：订票服务、机场服务、会员营销、旅客服务、行程规划、生活服务；
4. **商业与 KPI 层**：APP 活跃、订票转化、会员转化、客服分流、服务完成率；
5. **架构与部署层**：私有化部署、合规、多模型接入、灵活扩展。

招投标分析时应先做这种“项目本质判断”，再进入条款拆解，避免只做材料罗列。

## 3. 东航应标材料清单沉淀

### 3.1 五大类材料

1. **符合性评审材料**：不计分，但不满足可能被否决；
2. **经济标材料**：用于报价评分；
3. **商务标评分材料**：证书、备案、安全认证等；
4. **技术标评分材料**：方案、视频、案例、报告等；
5. **技术规格强制响应材料**：评分表之外的星号条款、承诺书和技术硬要求。

### 3.2 P0 符合性事项样例

| 序号 | 符合性项目 | 需准备 / 确认材料 |

| 2 | 法定代表人授权 | 法定代表人证明书、授权委托书、身份证明、签字盖章 |

| 5 | 信用中国 | 失信被执行人、重大税收违法查询截图 |

### 3.3 经济标材料样例

| 材料 | 要求 |
|---|---|
| 报价一览表 | 总价、税率、服务期一致 |
| 分项报价表 | 避免漏项 |

## 7. 合同风险与澄清问题沉淀

东航案例识别出的典型需澄清事项：

| 问题 | 为什么需要澄清 |
|---|---|
| `15 个工作日内完成交付` 与 `5 个月初验、6 个月上线、12 个月终验` 的关系 | 合同资料表与合同模板周期冲突，应明确以哪个为准，15 个工作日是否仅适用于标准产品开通 |
| 付款条款中 `终验（上线）` 与交货期中 `6 个月上线、12 个月终验` 的关系 | 付款节点术语混用，需明确第 3 期付款对应上线还是终验 |
| `明确约定交付的源代码` 范围 | 合同模板承认可能交付源代码，但未列具体范围，应明确模块、授权、第三方依赖和二开边界 |
| `全套技术文档` 边界 | 只明确模型部署手册、接口对接规范等，需明确是否包括运维手册、部署脚本、API 文档、数据字典、安全配置手册 |
| Computer/Mobile Use 是否为一期硬交付 | 原文标注为“规划与扩展方向”，不应默认作为一期硬承诺 |

## 8. 东航项目沉淀出的通用工作流

默认输出两个文档：

1. `项目名_应标清单.md`：只解决投标提交前的材料准备、评分响应和废标风险。
2. `项目名_交付物清单.md`：只解决中标后的履约交付、验收、付款、售后和合同风险。

执行顺序：

1. **先判项目本质**：这是产品采购、系统集成、平台建设、模型训练、运营服务，还是混合项目？
2. **第一遍抽取应标清单**：先抓 P0 否决项，再抓经济标、商务标、技术标、视频/证明、星号条款和排除项。
3. **第二遍抽取交付物清单**：切换到中标后视角，读取需求、技术规格、资源清单、合同资料表、服务订单、验收单、源代码/IP、售后和违约条款。
4. **拆评分表**：每一分都必须落到材料、证据、视频或方案。
5. **拆技术规格**：评分表之外的星号条款和承诺书单独管理。
6. **拆交付物**：中标后硬交付与投标期证明材料分开。
7. **拆合同风险**：付款、验收、源代码、知识产权、数据安全、违约冲突必须单独列。
8. **做能力匹配**：我方、原厂、伙伴分别能提供什么，缺什么。
9. **按 P0/P1/P2/P3/P4 排执行清单**：先废标风险，再直接得分，再强支撑，再强制响应，最后内部辅助。

## 9. 可复用检查问题

分析任意标书时，至少问：

- 这份标的核心目标是什么，采购人到底想买产品、平台、能力还是结果？
- 哪些条件不满足会直接废标？
- 评分表每一项有没有明确证据路径？
- 哪些材料必须原厂盖章或授权？
- 哪些评分项需要视频演示，视频要演示什么输入和结果？
- 经济标评审价格是含税还是不含税？
- 报价修正、漏项、控制价有什么阈值？
- 技术规格里有没有评分表之外的星号条款？
- 投标承诺会不会变成中标后硬交付？
- 交付节点和付款节点是否一致？
- 合同模板与合同资料表是否冲突？
- 源代码、知识产权、数据安全责任是否清楚？
- 哪些内容是一期硬交付，哪些只是规划方向？
- 内部辅助材料有没有被误列为评分必备？
