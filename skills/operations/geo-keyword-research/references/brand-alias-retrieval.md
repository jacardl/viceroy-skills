# 品牌别名检索与回写规范

适用场景：用户给定品牌名在公开搜索样本稀少，或品牌存在常见别名/译名/商品名（例如：必理通/必理痛/Panadol）。

## 执行规则

1. **双字段记录**：数据源表必须同时保存“展示查询词”（面向用户）与“实际检索词”（真实检索输入）。
2. **关键词统一回写**：最终 10+10 关键词统一使用用户给定品牌名，不直接输出别名词。
3. **方法区显式披露**：报告“研究方法”中写明别名映射关系，避免来源不透明。
4. **覆盖率解释**：若第二类品牌词样本偏低，说明是否受品牌词频或平台索引影响。

## 推荐映射写法

- `必理通（检索同义词：必理痛 / Panadol）`
- `莫匹罗星软膏（常见口语：百多邦）`

## 常见错误

- 只写最终品牌词，不记录别名检索输入，导致 URL 数据不可追溯。
- 报告中直接混用别名与主品牌名，造成关键词池口径不一致。
- 不说明别名来源，导致用户误解为“关键词编造”。

## 最小自检

- [ ] URLs 表含 `展示查询词` 与 `实际检索词` 两列
- [ ] 10+10 最终关键词均为用户给定品牌名
- [ ] 报告方法区含“别名映射”说明
- [ ] 覆盖比例按实际样本计算并可回溯到 URL 文件
